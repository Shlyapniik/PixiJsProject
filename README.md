# PixiJS Project

A 2D web project built with **PixiJS** and **JavaScript**.

## About

A small experimental project created to practice developing interactive 2D applications with PixiJS.

## Tech Stack

* JavaScript
* PixiJS 8
* Vite
* @pixi/sound

## Features

* 2D rendering with PixiJS
* Interactive gameplay elements
* Sound integration
* Browser-based application

## Project Status

**Completed / Archived**

This project was created as a learning and experimentation project with PixiJS.

## Running Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project will be available through the local Vite development server.
